# Perguntas Frequentes

**Pergunta:** Insirai o widget, mas não aparece nenhuma separador.

Resposta: O widget tem de estar **numa coluna de uma secção**. Se estiver
diretamente na página (sem layout de colunas), não há nada que possa servir
de separador. Insira uma secção, selecione o layout de colunas e arraste o widget para a coluna
.

**Pergunta:** Não vejo nenhuma barra de separadores no editor, apenas uma moldura
pontilhada — isto é um erro?

Resposta: Não, é intencional. No editor, todas as colunas permanecem visíveis e
podem ser editadas individualmente; caso contrário, não seria possível aceder ao conteúdo das guias inativas.
A barra de guias aparece na pré-visualização e na página publicada.
**Pergunta:** Onde insiro o conteúdo de uma guia?

**Pergunta:** Onde insiro o conteúdo de um separador?

Resposta: Não é no widget. O conteúdo é tudo o que se encontra **na mesma coluna**
abaixo do widget «Content Tabs» — textos, imagens e outros
widgets.

**Pergunta:** Só tenho uma coluna com o widget. Porque é que vejo apenas
um separador?

Resposta: Porque cada coluna selecionada é um separador, mesmo que haja apenas uma.
Para obter uma barra de separadores verdadeira, são necessárias, pelo menos, duas colunas, cada uma com um
widget «Separadores de Conteúdo».

**Pergunta:** Dois grupos de separadores foram acidentalmente agrupados num único.

Resposta: Todas as colunas diretamente adjacentes com o widget «Content-Tabs» formam
automaticamente um grupo comum. Coloque o segundo grupo numa **secção separada** —
ou deixe, pelo menos, uma coluna **sem** widget entre elas.

**Pergunta:** Coloquei dois widgets «Content-Tabs» na mesma coluna e,
mesmo assim, só aparece um separador.

Resposta: Exato — conta-se exatamente um separador por coluna. Para um segundo separador,
é necessária uma segunda coluna.

**Pergunta:** Posso alterar a ordem das abas posteriormente?

Resposta: Sim, movendo as colunas no editor. A ordem das abas
segue a ordem das colunas, da esquerda para a direita.

**Pergunta:** Posso criar um link para uma aba específica ou definir qual
aba é aberta primeiro?

Resposta: Não. Ao abrir a página, a primeira aba está sempre ativa e a
seleção não é guardada ao recarregar a página. Por isso, o conteúdo mais importante deve
ser colocado na primeira coluna.

**Pergunta:** Isto também funciona com separadores dentro de um separador?

Resposta: Não. Apenas são consideradas as colunas da mesma secção;
as secções dentro de uma coluna de separadores não se tornam em grupos de separadores adicionais.

**Pergunta:** É possível controlar a barra de separadores através do teclado?

Resposta: Sim. Utilize a tecla Tab para aceder à barra, as teclas de seta para a esquerda/direita
para alternar entre os separadores e as teclas Pos1/Fim para aceder ao primeiro ou ao último separador.
