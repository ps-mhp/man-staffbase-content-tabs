# Perguntas frequentes

**Pergunta:** Não vejo nenhuma barra de separadores no editor, apenas uma moldura
pontilhada — isto é um erro?

Resposta: Não, é assim mesmo. A barra de separadores só aparece na
página publicada; no editor, cada coluna permanece visível e
editável individualmente, identificada apenas pela moldura e pelo rótulo do título.

**Pergunta:** Por que razão dois grupos de colunas foram acidentalmente
agrupados num só?

Resposta: Todas as colunas adjacentes com um bloco «Content-Tabs» formam
automaticamente um grupo comum. Para separar dois grupos, é necessário que
haja, pelo menos, uma coluna entre eles **sem** bloco «Content-Tabs».

**Pergunta:** Posso alterar a ordem dos separadores posteriormente?

Resposta: Sim — a ordem dos separadores segue a ordem das
colunas na secção. Ao mover colunas no editor, a
ordem dos separadores altera-se em conformidade.
