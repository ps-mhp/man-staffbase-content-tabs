# Content-Tabs

Content-Tabs fasst benachbarte Spalten einer Section zu einer Tab-Gruppe
zusammen: Jede Spalte, in die ein Content-Tabs-Block gelegt wird, wird zu
einem eigenen Tab. Spalten ohne diesen Block bleiben unverändert und trennen
zwei Tab-Gruppen voneinander.

Das Widget eignet sich, um mehrere Inhalte auf demselben Platz unterzubringen,
ohne dass Leser:innen die Seite herunterscrollen müssen — etwa
Produktvarianten, Sprachfassungen nebeneinander oder mehrere Themenblöcke
innerhalb eines Abschnitts.

Im CMS-Editor ist keine Tab-Leiste zu sehen. Stattdessen markiert ein
gestrichelter Rahmen die Gruppe, mit dem jeweiligen Tab-Titel als Label, damit
jede Spalte beim Bearbeiten weiterhin einzeln erreichbar bleibt. Die
eigentliche Tab-Leiste erscheint erst auf der veröffentlichten Seite.
