# Schritt für Schritt

## Zwei Tabs anlegen

1. Seite im CMS zur Bearbeitung öffnen.
2. Einen **Abschnitt** (Section) einfügen und als Layout **zwei Spalten**
   wählen. Ohne Spalten funktioniert das Widget nicht — die Spalten sind das,
   was später zu Tabs wird.
3. In die **linke Spalte** das Widget **Content-Tabs** ziehen.
4. In den Widget-Einstellungen bei **Titel des Tabs** die Beschriftung
   eintragen, z. B. `Ankündigungen`, und speichern.
5. Unter das Widget — **in dieselbe Spalte** — den Inhalt legen, der in diesem
   Tab erscheinen soll: Text, Bilder, andere Widgets, beliebig viele Elemente.
6. Schritte 3 bis 5 für die **rechte Spalte** wiederholen, z. B. mit dem Titel
   `Termine`.
7. Seite speichern und in der **Vorschau** prüfen. Erst dort erscheint die
   Tab-Leiste mit den beiden Beschriftungen.

Ergebnis: zwei Tabs. Die Reihenfolge der Tabs entspricht der Reihenfolge der
Spalten von links nach rechts.

## Weiteren Tab hinzufügen

1. Dem Abschnitt eine weitere **Spalte** hinzufügen.
2. Ein Content-Tabs-Widget hineinziehen und ihm einen **Titel des Tabs** geben.
3. Den Inhalt darunter in dieselbe Spalte legen.
4. Speichern.

Es gibt keine Obergrenze. Passen die Beschriftungen nicht mehr nebeneinander,
lässt sich die Leiste seitwärts schieben.

## Tabs umsortieren

1. Im Editor die betreffende **Spalte** an die gewünschte Position schieben.
2. Speichern — die Tab-Reihenfolge folgt der Spaltenreihenfolge von links nach
   rechts.

## Einen Tab entfernen

1. Das **Content-Tabs-Widget** aus der Spalte löschen. Die Spalte ist damit
   kein Tab mehr, ihr Inhalt bleibt aber sichtbar und steht wieder normal auf
   der Seite.
2. Soll auch der Inhalt verschwinden, zusätzlich die **ganze Spalte** löschen.

## Zwei getrennte Tab-Gruppen auf einer Seite

Alle **direkt nebeneinanderliegenden** Spalten mit Content-Tabs-Widget werden
automatisch zu **einer** Gruppe. Für zwei getrennte Gruppen:

1. Einen **zweiten Abschnitt** anlegen (empfohlen) — über Abschnittsgrenzen
   hinweg wird nie gruppiert.
2. Dort die Spalten der zweiten Gruppe wie oben aufbauen.

Alternativ innerhalb desselben Abschnitts:

1. Zwischen die beiden Gruppen eine Spalte **ohne** Content-Tabs-Widget legen.
2. Diese Spalte trennt die Gruppen und erscheint selbst unverändert auf der
   Seite — sie kann leer bleiben oder eigenen Inhalt tragen.
