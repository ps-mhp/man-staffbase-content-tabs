# Einstellungen

| Einstellung | Beschreibung |
| --- | --- |
| Titel des Tabs | Die Beschriftung, unter der die Spalte als Tab erscheint. Pflichtfeld — ohne Titel bleibt der Tab im Editor unbeschriftet. |

Das ist die einzige Einstellung des Widgets. Die Tab-Gruppierung selbst
ergibt sich automatisch aus der Anordnung der Spalten:

1. In jede Spalte, die ein Tab werden soll, einen Content-Tabs-Block legen und
   ihm über „Titel des Tabs“ einen Namen geben.
2. Benachbarte Spalten mit Block bilden automatisch eine Gruppe — sie müssen
   nur nebeneinanderliegen.
3. Eine Spalte **ohne** Block beendet die Gruppe; diese Spalte selbst bleibt
   unverändert.
