# FAQ

**Question:** I added the widget, but no tab appears.

Answer: The widget must be placed **in a column within a section**. If it’s
placed directly on the page (without a column layout), there’s nothing that can
become a tab. Insert a section, select a column layout, and drag the widget
into the column.

**Question:** I don’t see a tab bar in the editor, just a dashed
border—is this a bug?

Answer: No, that’s by design. In the editor, all columns remain visible and
can be edited individually; otherwise, you wouldn’t be able to access the content of the inactive tabs.
The tab bar appears in the preview and on the published
page.

**Question:** Where do I enter the content for a tab?

Answer: Not in the widget. The content is everything that’s **in the same column**
below the Content Tabs widget—any text, images, and other
widgets.

**Question:** I only have one column with the widget. Why do I see a
single tab?

Answer: Because every selected column is a tab, even if there’s only one.
For a true tab bar, you need at least two columns, each with a
Content Tabs widget.

**Question:** Two tab groups were accidentally merged into one.

Answer: All directly adjacent columns containing a Content Tabs widget
automatically form a single group. Place the second group in its **own
section**—or leave at least one column **without** a widget in between
them.

**Question:** I placed two Content Tabs widgets in the same column, but
I still only see one tab.

Answer: That’s correct—only one tab is displayed per column. For a second tab,
you need a second column.

**Question:** Can I change the order of the tabs later?

Answer: Yes, by moving the columns in the editor. The tab order
follows the column order from left to right.

**Question:** Can I link to a specific tab or specify which
tab opens first?

Answer: No. When the page opens, the first tab is always active, and the
selection isn’t remembered when the page reloads. Therefore, the most important content should
go in the first column.

**Question:** Does this also work with tabs within a tab?

Answer: No. Only the columns within the same section are considered;
sections within a tab column do not become separate tab groups.

**Question:** Can the tab bar be controlled using the keyboard?

Answer: Yes. Use the Tab key to jump to the bar, the left/right arrow keys
to switch between tabs, and Home/End to go to the first or last tab.
