# FAQ

**Question:** I don't see a tab bar in the editor, just a dotted
border—is this a bug?

Answer: No, this is by design. The tab bar itself only appears on
the published page; in the editor, each column remains visible and
editable individually, marked only by the border and the title label.

**Question:** Why were two column groups accidentally merged into one
?

Answer: All adjacent columns with a Content Tabs block automatically form
a single group. To separate two groups, there must be
at least one column in between **without** a Content Tabs block.

**Question:** Can I change the order of the tabs later?

Answer: Yes—the order of the tabs follows the order of the
columns in the section. Moving columns in the editor changes the
tab order accordingly.
