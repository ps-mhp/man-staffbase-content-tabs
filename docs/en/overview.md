# Content Tabs

Content Tabs groups adjacent columns within a section into a tab group:
Each column containing a Content Tabs block becomes
its own tab. Columns without this block remain unchanged and separate
two tab groups from each other.

The widget is ideal for displaying multiple pieces of content in the same space
without requiring readers to scroll down the page—such as
product variants, language versions side by side, or multiple topic blocks
within a section.

No tab bar is visible in the CMS editor. Instead, a
dotted border marks the group, with the respective tab title as a label, so that
each column remains individually accessible during editing. The
actual tab bar only appears on the published page.
