# Content Tabs

With content tabs, you can arrange multiple pieces of content one above the other instead of one below the other:
A tab bar appears on the published page, and readers
can switch between the content with a click. This saves space—for example, for
product variants, locations, departments, or multiple topic blocks that would otherwise
result in a very long page.

## The Bottom Line

**One tab = one column.** In a section, you create multiple
columns side by side, place a Content Tabs widget in each column, and
fill the column below with the content that should appear in that tab.

The widget itself doesn’t display anything. It simply marks “This column
is a tab” and provides the label for it.

## What Readers See

A tab bar above the content. The first tab is always
active when the page opens. Clicking a label displays the content of the corresponding
column; the other columns are hidden. On narrow screens,
the bar remains single-line and can be scrolled horizontally.

The selection is not saved: After reloading the page,
the first tab is active again.

## What You See in the CMS Editor

**No tab bar.** While editing, all columns remain side by side
so you can access each tab’s content directly. Related
columns are marked only by a dashed border and a label with the
tab title. The actual tab bar only appears in the preview
and on the published page.
