# FAQ

**Frage:** Ich sehe im Editor keine Tab-Leiste, nur einen gestrichelten
Rahmen — ist das ein Fehler?

Antwort: Nein, das ist so gewollt. Die Tab-Leiste selbst erscheint erst auf
der veröffentlichten Seite; im Editor bleibt jede Spalte einzeln sichtbar und
bearbeitbar, markiert nur durch den Rahmen und das Titel-Label.

**Frage:** Warum wurden zwei Spaltengruppen versehentlich zu einer
zusammengefasst?

Antwort: Alle benachbarten Spalten mit einem Content-Tabs-Block bilden
automatisch eine gemeinsame Gruppe. Um zwei Gruppen zu trennen, muss
mindestens eine Spalte dazwischen **ohne** Content-Tabs-Block liegen.

**Frage:** Kann ich die Reihenfolge der Tabs nachträglich ändern?

Antwort: Ja — die Reihenfolge der Tabs richtet sich nach der Reihenfolge der
Spalten in der Section. Spalten im Editor verschieben, ändert die
Tab-Reihenfolge entsprechend mit.
